🔒 VULNERABILIDADES PROTEGIDAS
════════════════════════════════════════════════════════════════════════════════

✅ Inyección SQL
   ├─ Cliente valida entrada (prevención primaria)
   ├─ Servidor valida entrada (prevención secundaria)
   ├─ Parámetros SQL (prevención terciaria)
   └─ Ejemplos: '; DROP TABLE --, UNION SELECT, etc.

✅ Cross-Site Scripting (XSS)
   ├─ Cliente codifica salida (prevención primaria)
   ├─ CSP bloquea scripts inline (prevención secundaria)
   ├─ Validación en servidor (prevención terciaria)
   └─ Ejemplos: <script>, onload=, javascript:, etc.

✅ Manipulación de HTML del cliente
   ├─ Servidor valida permisos (prevención primaria)
   ├─ Servidor no confía en client (prevención secundaria)
   └─ Auditoría registra intentos (prevención terciaria)

✅ Carga de scripts no autorizados
   ├─ CSP define qué scripts cargar (prevención primaria)
   ├─ Monitoreo registra violaciones (prevención secundaria)
   └─ Ejemplos: <img src=x onerror>, etc.

⚠️ NO Protege (necesitan otras medidas):
   ├─ CSRF (CSRF tokens necesarios)
   ├─ Brute force (Rate limiting necesario)
   ├─ Phishing (educación de usuarios)
   ├─ Man-in-the-middle (HTTPS obligatorio)
   └─ Vulnerabilidades del SO (parches necesarios)
