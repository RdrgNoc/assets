🔐 PASO 2: CONFIGURAR CSP EN SERVIDOR (3 minutos)
════════════════════════════════════════════════════════════════════════════════

En tu archivo Global.asax, en el método Application_BeginRequest():

```csharp
protected void Application_BeginRequest()
{
    Response.Headers.Add("Content-Security-Policy", 
        "default-src 'self'; " +
        "script-src 'self' 'unsafe-inline' 'unsafe-eval' cdnjs.cloudflare.com code.jquery.com; " +
        "style-src 'self' 'unsafe-inline' cdnjs.cloudflare.com; " +
        "img-src 'self' data: https:; " +
        "connect-src 'self' https:; " +
        "frame-ancestors 'none'; " +
        "form-action 'self';");
}
```

✅ DONE: CSP activo


✏️ PASO 3: VALIDAR UN FORMULARIO (5 minutos)
════════════════════════════════════════════════════════════════════════════════

ANTES:
```javascript
function guardarDatos() {
    var nombre = $("#txtNombre").val();
    fetchDataArr(5, { nombre: nombre }, 9, function(response) { ... });
}
```

DESPUÉS:
```javascript
function guardarDatos() {
    // Definir reglas
    const rules = {
        nombre: { type: 'string', required: true, minLength: 3, maxLength: 100 }
    };
    
    // Validar
    const validation = validateAndPrepareData(
        { nombre: $("#txtNombre").val() },
        rules
    );
    
    if (!validation.valid) {
        showMsg(validation.errors.join('\n'), 'error');
        return;
    }
    
    // Preparar datos
    const secureData = prepareSecureData(validation.data, AUTOMATA_SLAYER_VERSION);
    
    // Enviar
    fetchDataArr(5, secureData, 9, function(response) { ... });
}
```

✅ DONE: Formulario seguro


📊 PASO 4: CODIFICAR SALIDA EN HTML (3 minutos)
════════════════════════════════════════════════════════════════════════════════

ANTES:
```javascript
fetchDataArr(1, {}, 9, function(response) {
    response.forEach(item => {
        $("#tabla").append(`<tr><td>${item.nombre}</td></tr>`);
    });
});
```

DESPUÉS:
```javascript
fetchDataArr(1, {}, 9, function(response) {
    response.forEach(item => {
        const nombreSeguro = encodeHTML(item.nombre);
        $("#tabla").append(`<tr><td>${nombreSeguro}</td></tr>`);
    });
});
```

✅ DONE: Salida segura


✔️ PASO 5: VALIDAR EN SERVIDOR (5 minutos)
════════════════════════════════════════════════════════════════════════════════

En tu controlador C#:

```csharp
[HttpPost]
public JsonResult GuardarDatos(string nombre, string _jsVersion)
{
    // Validar versión
    if (!ServerSecurityHelper.ValidateJsVersion(_jsVersion, "1.0.0"))
        return Json(new { flag = false, msg = "Versión inválida" });
    
    // Validar datos
    if (!ServerSecurityHelper.ValidateSafeString(nombre, 100))
        return Json(new { flag = false, msg = "Datos inválidos" });
    
    // Usar Parametrized Query
    using (SqlCommand cmd = new SqlCommand(
        "INSERT INTO TABLA (nombre) VALUES (@nombre)", 
        connection))
    {
        cmd.Parameters.AddWithValue("@nombre", nombre);
        cmd.ExecuteNonQuery();
    }
    
    return Json(new { flag = true, msg = "Guardado" });
}
```

✅ DONE: Servidor seguro
